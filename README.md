# NÓMA Expeditions

A premium travel portfolio concept by Sebastián Sánchez. Built with React, TypeScript, Vite, and a procedural Three.js globe. Original interface and code, with mountain photography served locally from Unsplash.

## Run

```sh
npm install
npm run dev
npm run build
npm run typecheck
npm test
```

## Experience

- Three destinations, responsive editorial layout, animated 3D globe, and accessible navigation.
- Itinerary planner with adjustable dates, trip duration, and traveler count; live USD estimates.
- Preferences persist in localStorage. Plans can be downloaded as text.
- Native accessible itinerary dialog, keyboard navigation, and reduced motion support.
- Static Vercel deployment; no secrets or external backend required.

This is a demonstration, not a travel agency. Prices, routes, and availability are illustrative. No payment, personal information, or reservation is submitted. Destination photography is illustrative and should not be treated as an exact depiction of a specific itinerary stop.
